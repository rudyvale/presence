Monero Miners Target Exposed SQL Servers via Weak Credentials

Presence Editorial · November 14, 2026 · 4 min read

FortiGuard Labs has identified a campaign targeting internet-facing Microsoft SQL Servers by exploiting weak database passwords to install Monero mining software and Gh0st RAT malware. This malicious code masquerades as a Microsoft Edge updater while consuming the server's processing power, enabling attackers to steal data and control infected machines.

Details regarding the operation were published in a Nov. 12 report by researcher Xiaopeng Zhang after the activity was discovered in early October 2026. The malware sustains access through registry changes, Windows services, and scheduled tasks, though the publication does not identify the attackers or provide a confirmed victim count.

Campaign Targets Internet-Facing Databases

FortiGuard Labs outlined a campaign in which malicious software scans for vulnerable databases and tries to authenticate using a credential list exceeding 2,700 passwords matched with accounts like 'sa' and 'admin.' Once inside the networks, adversaries issue database instructions to activate xp_cmdshell and deploy a retrieval tool that fetches the Monero cryptocurrency miner and Gh0st RAT malware from a server under attacker control.

Official guidance from Microsoft indicates that the xp_cmdshell feature is turned off by default on fresh SQL Server setups and ought to stay disabled in most cases. Although certain legacy programs may still depend on this capability, the vendor advises activating it solely for the duration of essential operations.

According to Microsoft's guidance, the xp_cmdshell utility is turned off on fresh SQL Server setups and ought to stay disabled unless legacy software demands it. The vendor suggests turning this function on solely for the duration of a required operation. Because any command issued via this path adopts the rights held by the SQL Server service account, Microsoft advises limiting access to top-tier users and employing a lower-privilege proxy account if non-administrators must utilize the capability.

The company indicates that a standard user needs a specific proxy credential configured to operate xp_cmdshell; lacking this credential causes the action to fail. Microsoft also cautions that activating or utilizing this feature may alert security auditing mechanisms. The mining component, identified as MicrosoftEdgeUpdate.exe, leverages the infected system's processor to extract Monero via XMRig. Zhang's review notes that its settings include a wallet address alongside three addresses for mining pools.

A second payload identified as winlogon.exe functions as a Gh0st RAT variant equipped with keylogging, file management, and remote command capabilities, while screen capture and remote desktop features are provided through plugins that were absent in the analyzed sample. Persistence mechanisms detailed in the report consist of registry entries, a Windows service, and scheduled tasks, with the RAT's scheduled task configured to run every 30 minutes.

Prior to analysis, the researchers chose not to connect the RAT to a live command server since that infrastructure had already ceased operations. In July 2024, adversaries leveraged vulnerable file-sharing servers to spread Monero miners and remote-access malware. AhnLab's investigation recorded assaults on Rejetto HTTP File Server involving the deployment of XMRig, XenoRAT, and Gh0stRAT.

AhnLab identified at least four attackers deploying mining software through exposed services, including the LemonDuck group. Researchers observed these intruders collecting system information and creating backdoor accounts, with many cases involving the termination of file servers after establishing access to prevent other attackers from utilizing them.

Following a recent patch from Apple addressing a macOS vulnerability, security researchers noted that adversaries had leveraged Screen Sharing capabilities to deploy Monero mining software. On August 12, the Netherlands' National Cyber Security Centre issued an advisory confirming breaches across numerous systems where the Screen Sharing port remained accessible online. The report indicated that threat actors secured root privileges and placed miners on all affected machines, highlighting a specific authentication flaw that permitted entry even without proper credentials, though patches for macOS Sequoia, Sonoma, and Tahoe were in place.

Malware Persistence and Payload Details

US cybersecurity firm CrowdStrike detected a distinct impersonation campaign in January 2025 that utilized fake recruitment offers to deceive job seekers. The company identified this specific operation on Jan. 7, 2025, noting that emails mimicking its recruiters directed targets to download an application falsely presented as an employee management tool. Analysis of the download page revealed options for both Windows and macOS systems, yet both paths delivered a single Windows executable written in Rust designed to fetch XMRig.

Prior to completing the installation, the malicious application executed several verification steps including checking for debugging software, counting active processes, and confirming that the CPU possessed at least two cores. After passing these checks, the malware displayed a fake error message before continuing to download the miner. CrowdStrike emphasized that it never requires candidates to download software as part of its legitimate recruitment process.
